# Agent Control Map

Who holds the keys of on-chain agent infrastructure. Public on-chain data only.

- Page: `index.html` (GitHub Pages)
- Data: `data/agent-control-map.json`
- Version: v1 draft, checked 2026-10-29
- Licence: CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Attribution: "Agent Control Map (@itpvl4)".

Each entry says whether an admin key exists, who holds it (as visible on-chain), and how to verify it yourself.
These are observations from public data, not vulnerability reports and not security advice.
A "plain address" means there is no contract code at that address; how a key is stored cannot be seen on-chain.

Corrections: open an issue.
